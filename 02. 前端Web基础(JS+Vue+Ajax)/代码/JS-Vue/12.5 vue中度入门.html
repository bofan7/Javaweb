🔁 3. v-for（复印机 - 批量生产）

🍎 遍历数组（像复印机，一份数据复印 N 份）

  • {{ index + 1 }}. {{ fruit.name }} - {{ fruit.price }}元/斤

👤 遍历对象（把对象拆开看）

{{ key }}: {{ value }}

💡 口诀：v-for 是复印机，:key 是身份证（防止搞混）

🔗 4. v-bind（属性魔法棒 - 简写 :）

🖼️ 绑定图片（图片地址来自 JS 变量）

🎨 动态 class（开关式加样式）

我的样式会根据数据变！

🎭 动态 style（直接绑定 CSS）

我的颜色是 {{ textColor }}，大小是 {{ fontSize }}px

💡 口诀：冒号(:) = 把 HTML 属性交给 JS 管

👆 5. v-on（事件捕手 - 简写 @）

🖱️ 点击事件（用户一动手，你就行动）

💬 传参数（带着参数去执行）

{{ greeting }}

⌨️ 键盘事件（回车触发）

搜索结果：{{ searchResult }}

🚫 事件修饰符（阻止冒泡/默认行为）

{{ onceMessage }}

💡 口诀：@ = 监听动作，修饰符 = 加特效

🔄 6. v-model（双向同步魔法）

✍️ 文本输入（你打字，变量同步；变量改，框里同步）

📝 多行文本

你的留言：{{ message }}

☑️ 复选框（单个：true/false）

状态：{{ agreed ? '✅ 已同意' : '❌ 未同意' }}

📻 单选框（多选一）

你的性别：{{ gender }}

📋 下拉框

你选的城市：{{ city || '未选择' }}

🔧 修饰符（给 v-model 加特技）

实际内容："{{ trimmedText }}"（长度：{{ trimmedText.length }}）

年龄类型：{{ typeof age }}，值：{{ age }}

内容：{{ lazyText }}

💡 口诀：v-model = 表单和数据自动同步，改哪边都行

🎓 一分钟速记表

指令 形象比喻 一句话记忆
v-text 老实人 只显示纯文字，HTML标签当文字
v-html 化妆师 渲染HTML，带样式显示
v-show 隐身衣 CSS隐藏，元素还在DOM
v-if 瞬移术 条件渲染，false直接消失
v-for 复印机 循环渲染，别忘加:key
:属性 魔法棒 绑定属性，JS变量控制
@事件 捕手 监听动作，用户一动就执行
v-model 镜像魔法 双向绑定，表单和数据同步
